# The-AI-Quiz
A Python application to test users on verifying if they are human or AI. It provides questions humans can solve, but AI can't answer. It helps clarify the distinction between humans and AI and improves security and data integrity, which can help prevent server slowdowns and stolen sensitive information.

# Content
* Application works with a GUI, or graphical user interface
* Intro page telling what the quiz is about.
* (5 or 10)-question Quiz
* Select order of questions
* Different types of question in answering.
* The quiz kicks out any user who answers wrong, thinking it's the AI.
* Colors/Designs to help the application look less bland and dull.
* Ending page verifying the user is a human.
* Friendly interface to be welcoming to all users.
# Goals
* Make sure application runs properly
* Test the quiz on an actual AI
* Test on a human
* Have a good interface.
